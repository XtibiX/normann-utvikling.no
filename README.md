## Om meg

Med over 14 års erfaring i IT-bransjen har jeg funnet min lidenskap i å skape verdi gjennom godt håndverk og sterke team. Som Tech Lead handler det ikke bare om å levere kode, men om å bygge løsninger som faktisk løser reelle problemer og som kan vokse med virksomheten.

Jeg tror på at de beste løsningene kommer fra team som jobber godt sammen, der teknisk dyktighet kombineres med god kommunikasjon og en kultur for læring. Min rolle er å legge til rette for dette – både ved å dele min tekniske erfaring og ved å skape et miljø der alle kan bidra med sitt beste.

Fra kritiske backend-systemer for finanssektoren til sanntidsløsninger for transport og energi – jeg har hatt gleden av å jobbe med systemer som betyr noe. Det som driver meg er å kombinere teknisk dypdykk med pragmatisk problemløsning, alltid med fokus på å levere reell verdi til brukerne.
