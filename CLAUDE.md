# CLAUDE.md

Personal site for Normann Utvikling (Rolf Erik Normann, Tech Lead & backend developer), live at https://normann-utvikling.no.
Originally generated by Lovable; fully redesigned and detached from Lovable since then.

## Commands

Node 22 is installed at `~/.local/node` and is **not** on the default PATH. Prefix commands with it:

```sh
export PATH=$HOME/.local/node/bin:$PATH
npm ci
npm run dev       # http://localhost:8080
npm run build     # production build in dist/
npx tsc -p tsconfig.app.json --noEmit   # typecheck
npm run lint      # 2 pre-existing errors in src/components/ui (stock shadcn), ignore
```

npm is the package manager (`package-lock.json`). Do not reintroduce `bun.lockb`.

## Structure

- `src/pages/Index.tsx` composes the one-page site and owns the scroll-reveal hook (`[data-reveal]` → `.is-visible`).
- Sections in `src/components/`, in page order: `Navbar`, `Hero`, `Clients`, `About`, `TechnicalExpertise`, `Skills`, `Experience`, `Contact`, `Footer`.
  `SectionHeading` is the shared numbered heading (`index`, `label`, `title`, `tone="light" | "dark"`).
- Section anchors: `#top`, `#om`, `#kompetanse`, `#experience`, `#contact`.
- `src/components/ui/` is stock shadcn/ui; mostly unused. Leave it alone unless needed.
- Content (CV data) lives as arrays at the top of each section component.
- `Experience` has three parts: `experiences` (shown in full: TET Digital, Passasjertelling, Normann Utvikling, SpareBank 1), `earlier` (2012–2018, shown as a compact list with a "Les mer om tidligere oppdrag" toggle that swaps in the full entries, rendered with `hidden` and without `data-reveal`), and `background` (Utdanning and Arbeidsgivere, always visible). The `offset` counter runs across both lists.
- `Skills` has six categories in a 3-column grid on `xl` (2 on `sm`).

## Design system

Tokens are HSL in `src/index.css`, exposed as Tailwind colors in `tailwind.config.ts`. Use tokens, never hard-coded colors.

| Token | Tailwind | Use |
|---|---|---|
| `--paper` `43 30% 94%` | `paper`, `paper-deep` | Page background (warm off-white) |
| `--ink` `216 12% 9%` | `ink` | Text, dark sections, buttons |
| `--signal` `193 53% 61%` (#68BAD1) | `signal` | The single accent, sampled from the profile photo background. Fills, dots, accent text on dark backgrounds |
| `--signal-ink` `194 62% 30%` | `signal-ink` | Accent for small text on the light background (light teal is too faint there) |

- No orange anywhere (the original accent was replaced by request).
- Fonts (Google Fonts in `index.html`): `font-serif` Instrument Serif for headings, `font-sans` IBM Plex Sans for body, `font-mono` IBM Plex Mono for labels. `.eyebrow` is the small mono uppercase label style.
- Profile photo in `About` is always grayscale (no hover colour) on a `bg-signal` offset block.
- Motion: the hero "Kafka stream" panel scrolls (`animate-stream`); the client list is static on purpose (a scrolling marquee was rejected as too much). All motion is disabled under `prefers-reduced-motion`.
- Favicon: `public/favicon.svg` ("n." mark), plus `favicon-32.png` and `apple-touch-icon.png` rendered from it. Regenerate the PNGs if the SVG changes.
- `brand/` (git-ignored, local only) holds the LinkedIn logo and cover as HTML sources plus rendered PNGs, in the same design. Re-render with a headless browser at 2x if the design changes.
- Check layouts at 390px wide as well as desktop; the hero grid needs `grid-cols-1` on mobile to avoid overflow.

- DNS at domene.shop ("DNS-pekere"): four `A` records on the apex → `185.199.108-111.153`, `www` CNAME → `xtibix.github.io`. Leave e-mail records alone.
- Pushing to `main` publishes to the live site. Only push when the user asks.
- `backup/lovable-original` is a local-only branch with the original Lovable design.
- The local `gh` CLI is logged in as `Normann-TET`, which cannot change settings on the XtibiX repo; repo settings must be changed by the user.
